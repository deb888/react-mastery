# React Mastery

Interactive React learning playground. 25 topics, each with MD guide + live interactive component.

## Stack

Vite + React 18 + React Router v6. Dark mode. Lazy-loaded playgrounds.

## Quick Start

```bash
npm install
npm run dev
```
